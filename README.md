# GIS Day 2026

Resources from the Esri GIS Day 2026 Media Kit
(https://storymaps.arcgis.com/briefings/1228b872d0fd43d1a8343348b67bf8e8) and presentations built from them.

- `resources/briefing.json` – raw briefing content (text, links, layout)
- `resources/social/` – 2026 social images/stickers
- `resources/poster/` – 2026 printable poster
- `resources/backgrounds/` – virtual backgrounds
- `resources/guides/` – Teacher for a Day guide (PDF)
- `resources/item-resources/` – all images embedded in the briefing
- `presentations/` – generated decks (`node src/build.js`, needs `npm install`)

Not downloaded (links only): videos on YouTube/Esri MediaSpace, the "GIS Day in the Classroom" implementation guide (URL returns 404), the certificate on community.esri.com, the StoryMaps template.
All Esri material remains Esri's; check usage terms before redistributing.
